# Homebrew Tap for MailVault Pro

Official Homebrew Cask tap for **[MailVault Pro](https://mailvaulty.com/)** — local-first Microsoft 365 & New Outlook email archiving into SQLite FTS5 + Obsidian Markdown (OKF).

## Install (macOS Apple Silicon)

```bash
brew install --cask khaledsabae/tap/mailvault-pro
```
